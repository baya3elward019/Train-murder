# القطار الأخير

لعبة تحقيق وغموض سينمائية في المتصفح. خريف ١٩٥٨، آخر رحلة لإكسبريس الوادي: صاحب الخط اتقتل في صالونه، والقطر مش هيقف قبل ١٢:٣٠. خمس ركاب، كل واحد عنده سبب، وواحد بس عملها.

**العب:** افتح `index.html`، أو من GitHub Pages: `https://baya3elward019.github.io/Train-murder/`

## اللعبة فيها إيه

- **خمس فصول:** الركوب، الحادثة، التحقيق، الأسرار، الدقايق الأخيرة، وبعدها مواجهة أخيرة مع المتهم.
- **قاتل مختلف كل قضية:** أي واحد من الخمسة ممكن يكون القاتل، والأدلة والأقوال بتتغير معاه. الحل دايمًا منطقي: كل بريء عنده دليل مادي يثبت مكانه الساعة ١٠:٤٠، والقاتل دليله بيكدّبه.
- **تحقيق حقيقي:** افحص، فتّش، اسأل، اضغط، واجه بدليل، بلِّف، راقب.
- **لوحة أدلة:** اربط دليلين ببعض، والربط الصح بيطلّع استنتاج جديد يتستعمل كدليل.
- **شخصيات بتتفاعل:** كل واحد له ثقة وتوتر، وبيكدب في حاجة حتى لو بريء.
- **وقت بيمشي مع كل تصرف:** ناس بتتحرك، شاهد بيفتكر، المطر بيبوّظ ورقة، والقاتل بيتخلص من دليل في النفق التاني.
- **ست نهايات**، منهم واحدة سرّية.
- **حفظ تلقائي** على الجهاز، وشغالة على الموبايل والكمبيوتر.

## الملفات

| الملف | بيعمل إيه |
|---|---|
| `index.html` | الصفحة |
| `css/style.css` | الهوية البصرية والواجهة |
| `js/engine.js` | الحالة، الشروط، الوقت، الأحداث، الحفظ. مفيش فيه رسم ولا قصة |
| `js/scene.js` | رسم العربيات والشخصيات والإضاءة على canvas |
| `js/ui.js` | القوائم، الحوار، ملف القضية، الألعاب الصغيرة، المواجهة، النهايات |
| `js/audio.js` | الصوت (متولّد بالكود) |
| `cases/case01.js` | كل محتوى القضية كبيانات |

مفيش مكتبات ولا خطوة build.

## إضافة قضية جديدة

انسخ `cases/case01.js`، غيّر الـ `id` والمحتوى، وضيف سطر `<script>` ليها في `index.html`. القضية عبارة عن كائن واحد فيه:

`locations` · `chars` (المواضيع، الردود على الأدلة، البلفة، المواجهة) · `evidence` · `hotspots` · `bags` · `links` (روابط اللوحة) · `events` (مربوطة بالساعة) · `acts` · `timeline` · `intro` · `accuse` · `endings` · `setup` (اللي بيتغير كل جولة)

الشروط نصوص بسيطة: `"flag"`، `"!flag"`، `"t>=80"`، `"trust:nabil>=3"`، `"killer:awad"`، `"at:awad:c5"`.

## استبدال الأصوات بملفات

حط الملف في `audio/` وسجّله في أول `js/audio.js`:

```js
LT.audio.files.door = 'audio/door.mp3';
```

الأسماء المتاحة: `train` `rain` `wind` `drone` `tick` `static` (مستمرة)، و`step` `door` `clue` `link` `blip` `page` `warn` `bell` `thunder` `chime` `stab` `open` (لمرة واحدة).
