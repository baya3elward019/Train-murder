# القطار الأخير

لعبة تحقيق وغموض في المتصفح. جريمة في قطار ليلي وساعة واحدة قبل المحطة: دوّر بالكشاف على الأدلة، استجوب الركاب، فك إشارات اللاسلكي، وفتّش الشنط من غير ما تتقفش. القاتل والأدلة بيتغيروا كل جولة.

## التشغيل

افتح `index.html` في المتصفح. ملف واحد من غير أي تثبيت.

## النشر على GitHub Pages

Settings ← Pages ← Deploy from a branch ← `main` / root.
